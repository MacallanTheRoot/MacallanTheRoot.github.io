Web Grenade & Explode: Offensive Browser Extensions

Author

Hamza Efe Şahinbaş

Date

2026

Stack

JavaScript HTML/CSS Web API

Developed to maximize efficiency during web penetration testing, these extensions have reached hundreds of downloads globally, serving security researchers worldwide.

Sometimes the fastest way to manipulate requests, test inputs, and analyze client-side security is right from the browser. Web Grenade and Web Explode are custom-built extensions that simplify complex web testing tasks.

Why Browser Extensions? Traditional proxy tools like Burp Suite are essential, but having lightweight, purpose-built extensions executing native DOM manipulations and API injections offers a seamless complementary approach. They allow for rapid, on-the-fly fuzzing and exploitation.

Community Impact: Together, these tools have crossed hundreds of active installations, proving that developers and security analysts value fast, robust, and accessible tools within their immediate workflow.

"Bringing offensive security directly to the client side."
